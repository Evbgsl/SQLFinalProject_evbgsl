# Итоговый проект по дисциплине «Базы данных»

## Описание проекта

Данный проект представляет собой итоговое задание по дисциплине «Базы данных» и направлен на закрепление практических навыков работы с языком SQL.

В рамках проекта реализованы:
- создание реляционных баз данных;
- наполнение таблиц тестовыми данными;
- написание SQL-запросов различной сложности;
- анализ данных с использованием агрегатных функций, объединений и рекурсивных запросов.

Проект включает решения задач для четырех предметных областей:
- транспортные средства;
- автомобильные гонки;
- бронирование отелей;
- структура организации.

## Цель и задачи проекта

Цель проекта: освоение практического применения SQL для работы с реляционными базами данных.

Основные задачи:
- разработка структуры баз данных;
- установление связей между таблицами;
- выполнение выборок с использованием JOIN;
- агрегирование и фильтрация данных;
- объединение результатов запросов;
- работа с иерархическими структурами (WITH RECURSIVE).

## Структура базы данных и реализованные функции

Проект включает четыре независимые базы данных.

### 1. Vehicles
Содержит информацию о транспортных средствах.

Таблицы:
- Vehicle - производители и модели;
- Car - автомобили;
- Motorcycle - мотоциклы;
- Bicycle - велосипеды.

Связи:
- Car, Motorcycle, Bicycle → Vehicle (через model).

### 2. Racing
Содержит информацию о гонках и результатах.

Таблицы:
- Classes - классы автомобилей;
- Cars - автомобили;
- Races - гонки;
- Results - результаты.

Связи:
- Cars → Classes;
- Results → Cars и Races.

### 3. Hotel
Моделирует систему бронирования отелей.

Таблицы:
- Hotel - отели;
- Room - номера;
- Customer - клиенты;
- Booking - бронирования.

Связи:
- Room → Hotel;
- Booking → Room и Customer.

### 4. Organization
Описывает структуру компании.

Таблицы:
- Departments - отделы;
- Roles - роли;
- Employees - сотрудники;
- Projects - проекты;
- Tasks - задачи.

Связи:
- Employees → Employees (иерархия через ManagerID);
- Employees → Departments, Roles;
- Projects → Departments;
- Tasks → Employees и Projects.

## Используемые технологии

- MySQL (СУБД);
- XAMPP (локальный сервер);
- phpMyAdmin (веб-интерфейс для работы с базой данных);

## Инструкция по запуску

1. Создать базы данных в MySQL (например):
    - vehicles_db
    - racing_db
    - hotel_db
    - organization_db

2. Подключиться к серверу MySQL через SQL-клиент (например, DBeaver или phpMyAdmin).

3. Выбрать нужную базу данных (через интерфейс SQL-клиента или командой USE <имя_базы>).

4. Выполнить скрипты для каждой предметной области:

### 01_vehicles
- выполнить `01_vehicles/create.sql` - создание таблиц;
- выполнить `01_vehicles/insert.sql` - заполнение тестовыми данными;
- выполнить запросы из `01_vehicles/solutions.sql`.

### 02_racing
- выполнить `02_racing/create.sql`;
- выполнить `02_racing/insert.sql`;
- выполнить запросы из `02_racing/solutions.sql`.

### 03_hotel
- выполнить `03_hotel/create.sql`;
- выполнить `03_hotel/insert.sql`;
- выполнить запросы из `03_hotel/solutions.sql`.

### 04_organization
- выполнить `04_organization/create.sql`;
- выполнить `04_organization/insert.sql`;
- выполнить запросы из `04_organization/solutions.sql`.

## Тестирование

Проверка корректности решений осуществляется путем выполнения SQL-запросов из файлов `solutions.sql` после создания таблиц и загрузки данных.

Полученные результаты необходимо сравнить с ожидаемыми результатами, указанными в задании.
